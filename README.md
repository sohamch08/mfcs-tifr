## Course Overview

A foundational course in **combinatorics** and its applications in theoretical computer science. Topics include:

1. **Twelve Problems: $n$ Balls in $m$ Bins** — counting principles and combinatorial identities
2. **Stirling Numbers** — Stirling numbers of the first and second kind
3. **Inclusion-Exclusion Principle** — sieve methods and applications
4. **Generating Functions** — ordinary and exponential generating functions
5. **Partitions** — integer partitions and partition identities
6. **Partially Ordered Sets (Posets)** — chains, antichains, Dilworth's theorem, and related results
7. **Probabilistic Method** — existence arguments via probability
8. **Linear Algebraic Techniques in Combinatorics** — dimension arguments and polynomial method
9. **Projective Planes** — combinatorial geometry and constructions

> The full table of contents can be found inside the notes.
